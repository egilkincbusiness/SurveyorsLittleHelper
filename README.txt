Surveyor's Little Helper - iteration 1
Put every file in this folder at the top level of a GitHub repository (keep the data and icons folders), then turn on GitHub Pages.
To add surveyor names: edit data/surveyors.json, one line per license like  "657": "Lastname"
Test without GPS: add ?lat=42.5985&lon=-97.6451 to the web address (optionally &r=1.5 for miles).
